# Russian Region Hunter (RRH) 📡

**Russian Region Hunter (RRH)** — мониторинг несработанных регионов России для получения диплома «Россия». Программа отслеживает активность станций в реальном времени через [PSKReporter](https://pskreporter.info) и показывает, в каких несработанных регионах сейчас есть станции.

---

## 🎯 О дипломной программе «Россия»

Диплом **«Россия»** выдаётся за проведение связей со всеми **регионами** (субъектами) Российской Федерации. Всего существует **89 регионов** (области, края, республики, города федерального значения, автономные округа).

Программа RRH помогает:
- 🔍 Найти станции из **несработанных** регионов
- 📊 Отследить активность по **9 диапазонам** (160M — 10M)
- ✅ Отмечать сработанные станции
- 🎯 Сосредоточиться на **цифровых модах** (в первую очередь), в будущем будет добавлен SSB и CW

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📡 **Двойной мониторинг** | Приёмники **и** передатчики на 9 диапазонах |
| 🗺️ **Определение региона** | По позывному через справочник [СРР](https://award.srr.ru) |

| ✅ **Отметка сработанных** | Чекбокс в каждой строке, сохранение в файл |

| ⏱️ **Опрос каждые 2 минуты** | С учётом лимитов PSKReporter |
| 💾 **Сохранение данных** | Отработанные станции не теряются после перезапуска |
| 🎨 **Тёмная тема** | Удобна для длительного использования |

## 📸 Интерфейс

Веб-интерфейс выполнен в тёмной теме с интуитивной структурой:

**Верхняя панель:**
- ⏱️ Таймер до следующего опроса PSKReporter
- 📊 Карточки статистики: Активных, 👂 Слушают, 📡 Передают, ✅ Сработано, Уник. регионов

**Фильтры:**
- 📻 По диапазону (160M — 10M)
- 🔄 По типу станции (приёмник / передатчик)
- 🔍 Поиск по позывному или региону

**Таблица станций:**
- ✓ Чекбокс для отметки сработанного
- 🕐 Время обнаружения
- 📞 Позывной
- 👂/📡 Тип (СЛУШАЕТ / ПЕРЕДАЁТ)
- 🗺️ Код региона и полное название
- 📊 Диапазон
- 📈 Частота в МГц

## 🚀 Установка

### Требования

- **Python 3.8+**
- Аккаунт на [Hamlog](https://hamlog.online)

### Шаги установки

1. Скачай репозиторий

2. Установи зависимости  
pip install -r requirements.txt

3. Сохрани страницу статистики с Hamlog
Войди в аккаунт
Зайди на https://hamlog.online/account/rregions.php
Сохрани страницу как hamlog_page.html в папку проекта
Тип файла: «Веб-страница, только HTML»
⚠️ Файл hamlog_page.html не загружается в репозиторий (личные данные). Он нужен только локально.

5. Сгенерируй список несработанных регионов
python hamlog_parser.py
Программа создаст файл needed_regions.json со списком несработанных слотов по всем 9 диапазонам.

6. Запусти веб-интерфейс
python app.py

7. Открой в браузере
http://127.0.0.1:5000

⚙️ Конфигурация
Все настройки в файле config.py.

Чёрный список скимеров
Список EXCLUDED_DECODER_SOFTWARE содержит подстроки для автоматического отсева:
Веб-SDR (публичные приёмники без оператора):
kiwisdr — KiwiSDR
openwebrx — OpenWebRX
websdr — WebSDR
web-888
Автоматические декодеры:
cwsl_digi — CWSL_DIGI
decodium — Decodium
ft8tw, ft8af, ft8web — автодекодеры FT8
n1dq-ka9q-radio — автодекодер
wsprdaemon — WSPR мониторинг
psk-recorder — запись без оператора
skimmer — все виды скимеров
